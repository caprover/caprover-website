title: HTTP Analytics with GoAccess
slug: /server/goaccess
---

GoAccess provides HTTP traffic reports based on web server logs. Enable it through the dashboard's monitoring or analytics controls and select an application/report to inspect request patterns.

If a report is empty, generate traffic to the selected app, allow log processing time, and verify its web access logs and the GoAccess service. Handle raw logs and reports as potentially sensitive data. For application errors, use [Diagnostics](./diagnostics.md) and app logs as well.
