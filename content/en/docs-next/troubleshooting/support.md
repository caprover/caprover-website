First choose the [troubleshooting route](./index.md) that matches your symptom, then collect [diagnostics](./diagnostics.md). Search existing [CapRover discussions](https://github.com/caprover/caprover/discussions) and [issues](https://github.com/caprover/caprover/issues) for the exact error.

For configuration advice, ask in GitHub Discussions with the CapRover and Docker versions, relevant sanitized logs, deployment method, and steps tried. For a reproducible product defect, [report a bug](./report-bug.md). Do not publish secrets, private SSH keys, or an unredacted backup.
