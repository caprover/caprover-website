---
id: install
title: Install a One-Click App
slug: /one-click-apps/install
---

Open **One-Click Apps** in the dashboard, search the current catalog, and choose a template. Read its description, required variables, image versions, exposed ports, and start/end instructions before deploying. The catalog changes independently of this documentation, so use the template shown in your dashboard as the immediate source.

Provide unique credentials for databases and admin accounts. Choose persistent storage for services that keep data, confirm the container paths and node placement, then deploy. Wait for every generated service to become healthy and follow any post-install instructions displayed by the template.

Inspect the resulting apps individually under **Apps**. Verify their domains, HTTPS, persistent directories, and backup needs. A one-click template is a way to create CapRover apps; the generated services still require ordinary operations and recovery planning.
