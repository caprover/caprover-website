slug: /one-click-apps/custom-repositories
---

CapRover can load One-Click templates from a repository other than its default catalog. Add a trusted repository through the One-Click Apps settings, then browse its templates in the dashboard.

Templates can create services, set environment values, publish ports, mount storage, and run image builds. Review the source repository and the exact template before deploying it, especially credentials, default image tags, and public exposure. Keep track of which repository supplied an installed app so future upgrades can be evaluated against that template's changes.

To create your own template, see [Authoring One-Click Apps](./authoring.md).
