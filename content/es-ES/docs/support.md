### ¿Dónde obtener soporte?

Si estás reportando un error o tienes una solicitud de función, puedes usar GitHub issues:
https://github.com/caprover/caprover/issues

Si necesita ayuda con la implementación y algo no funciona del todo, envíe un mensaje a [**Slack Chat**](https://join.slack.com/t/caprover/shared_invite/zt-3lmngygtv-MOIiGy~LHkZ6S8sbYYqTDA) o use [**GitHub Issues**](https://github.com/caprover/caprover/issues).

### ¿Necesita un sistema hermético?

CapRover utiliza muchos servicios para alojar código, crear, controlar el estado y ejecutar, como GitHub, Google, Docker Hub, etc. También aloja muchas aplicaciones de terceros, ya sea en forma de complementos (como NetData) o aplicaciones de un clic. Estas aplicaciones pueden utilizar servicios de terceros, es decir, sus servicios backend. Si necesita ejecutar CapRover en una situación hermética, por ejemplo, un entorno que no tiene acceso a Internet, contáctenos para obtener asistencia privada `support at/caprover/dot/com`.
