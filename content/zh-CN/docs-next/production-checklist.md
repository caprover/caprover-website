在托管重要应用程序之前, 请检查 :

- **访问**
  - 更改初始密码 。
  - 启用dashboard HTTPS 和 **Force HTTPS**.
  - 限制直接进入端口 `3000`.
  - 使用有限的证书进行自动化.
- **DNS 和 HTTPS 软件**
  - 验证通配符 DNS 。
  - 检查dashboard和应用程序证书。
  - 为未来的服务器移动计划 DNS 更改 。
- **数据**
  - 使用容积或绑定挂载进行持久化数据。
  - 分别备份数据库,上传,以及其他应用数据.
  - 注意节点设置, 用于本地存储 。
- **恢复**
  - 存储 CapRover 配置备份以关闭服务器 。
  - 测试一个应用数据恢复 。
  - 记录镜像位置、节点放置和注册访问。
- **能力**
  - 离开 CPU, RAM, 和磁盘头室进行构建 。
  - 监视磁盘的使用 。
  - 选择保存有用回滚的镜像清理策略 。
- **网络**
  - 只开放必要的公共端口。
  - 将 Swarm 节点间端口限制为信任的节点 。
  - 审查每个公布的TCP/UDP应用端口. Docker公布的端口可以绕过简单的UFW规则.
- **升级**
  - 测试您的应用程序的部署和升级。
  - 保持备用状态
  - 配置健康检查以满足您的可用需求 。
