在生产环境运行重要应用前，请检查以下事项：

- **访问控制**
  - 修改初始密码。
  - 为 dashboard 启用 HTTPS 和 **Force HTTPS**。
  - 限制公网直接访问 `3000` 端口。
  - 自动化任务使用最小权限凭据。
- **DNS 与 HTTPS**
  - 确认通配符 DNS 解析正常。
  - 检查 dashboard 和各应用的 TLS 证书。
  - 提前规划以后迁移服务器时需要修改的 DNS 记录。
- **数据**
  - 使用 Docker 数据卷或 bind mount 持久化数据。
  - 分别备份数据库、上传文件及其他应用数据。
  - 使用本地存储时，注意应用与数据所在节点的对应关系。
- **恢复**
  - 将 CapRover 配置备份存放在服务器之外。
  - 实际测试应用数据的恢复过程。
  - 记录镜像所在位置、节点调度要求和 registry 访问方式。
- **资源容量**
  - 为构建任务预留 CPU、内存和磁盘空间。
  - 监控磁盘使用情况。
  - 配置镜像清理策略，同时保留回滚所需的版本。
- **网络**
  - 仅开放必要的公网端口。
  - Swarm 节点间通信端口仅对可信节点开放。
  - 检查每个应用发布的 TCP/UDP 端口。Docker 发布端口可能绕过普通 UFW 规则。
- **升级**
  - 在实际应用上验证部署和升级流程。
  - 保留可恢复的备份。
  - 根据可用性要求配置 health check。

先阅读[快速入门](get-started.md)。日常维护参阅[服务器管理](server/index.md)。
