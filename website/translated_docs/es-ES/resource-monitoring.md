<br/>

Siempre querrás ver cómo se comporta tu aplicación. ¿Te está consumiendo la memoria o CPU? ¿O tu conexión de red es lenta? Puede responder todas estas preguntas visitando el menú Captain Monitoreo desde el panel web. Puede habilitar [NetData](https://github.com/netdata/netdata), que es una herramienta de monitoreo de servidor, y monitorear su servidor.
