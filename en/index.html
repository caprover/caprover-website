Edit the full per-app NGINX template

CapRover generates routing and TLS automatically. Open the app’s full NGINX template when you need custom headers, IP rules, basic auth, caching, redirects, larger uploads, or custom proxy timeouts.

HTTP Settings → NGINX template
client_max_body_size 1g;
add_header X-Frame-Options
  SAMEORIGIN;
proxy_read_timeout 300s;

Deploy from your terminal, Git, images, or Compose.

Ship an app or worker with one command

Run a web app, API, or private background worker. caprover deploy packages your committed local files and builds directly on your VPS.

Dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY worker.py .
CMD ["python", "worker.py"]
$ caprover deploy
✓ Image built · Swarm service updated

Point your captain-definition file to ./Dockerfile before deploying—no Git-provider OAuth required.

Publish a static site

Serve plain HTML or ship your frontend build output directly from your workstation.

Dockerfile
FROM nginx:alpine
COPY ./public/ /usr/share/nginx/html/
$ caprover deploy
✓ Image built · Swarm service updated

Point your captain-definition file to ./Dockerfile before deploying—no Git-provider OAuth required.

Import a prebuilt Compose stack

Paste a supported Docker Compose YAML to create standard CapRover-managed apps. v1.16 warns about ignored fields such as build or custom networks.

compose.yaml
services:
  web:
    image: nginx:alpine
  cache:
    image: redis:7-alpine
Apps → Docker Compose → Paste YAML
✓ Stack parsed · Managed services ready
