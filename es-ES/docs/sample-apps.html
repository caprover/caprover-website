Aplicaciones de muestra


CapRover está construido sobre el contenedor Docker. Por lo tanto, prácticamente todas las aplicaciones se pueden implementar en CapRover. Como se menciona en los documentos captain-definition, existen algunas versiones simples de captain-definition para los lenguajes web más populares, como NodeJS, PHP, python y ruby.

Sin embargo, CapRover no se limita a estos idiomas. Por ejemplo, puede implementar una aplicación go. Solo necesitas un Dockerfile para ello.

¡Listo para ser implementado!​

Dentro del repositorio CapRover, puede encontrar una colección de diferentes aplicaciones de muestra que están listas para implementarse. Ver: https://github.com/caprover/caprover/tree/master/captain-sample-apps

Hay:

  • ASP.NET
  • Ir a la aplicación
  • nginx aplicación avanzada
  • Python
  • Ruby
  • Elixir/Phoenix/LiveView
  • NodeJS
  • Aplicación React
  • y etc...

Para implementar aplicaciones de muestra, solo necesita:

  • Descarga el archivo tar de tu elección.
  • Vaya a su panel web CapRover y cree una aplicación de prueba.
  • Vaya a la pestaña "Implementación" y cargue el archivo tar.
  • ¡¡Hecho!!

Ahora puedes descomprimir el contenido tar y ver qué hay dentro. Esto le dará una idea de cómo se pueden implementar diferentes aplicaciones usando CapRover (Docker).
