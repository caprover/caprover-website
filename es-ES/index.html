Edita la plantilla NGINX completa por aplicación

CapRover genera el routing y TLS automáticamente. Abre la plantilla NGINX completa de la app cuando necesites cabeceras personalizadas, reglas por IP, autenticación básica, caché, redirecciones, límites de carga mayores o timeouts de proxy propios.

HTTP Settings → Plantilla NGINX
client_max_body_size 1g;
add_header X-Frame-Options
  SAMEORIGIN;
proxy_read_timeout 300s;

Aplica overrides a servicios Docker y hooks

Gestiona variables de entorno, volúmenes y réplicas desde el panel. Usa Service Update Override en JSON o YAML para límites de memoria, bind mounts de solo lectura o healthchecks, o una Pre-Deploy Function en JavaScript.

App Configs → Service Update Override

  Resources:
    Limits:
      MemoryBytes: 536870912

Escala de un VPS a nodos worker de Swarm

Docker Swarm funciona desde el primer día. Crea un registro privado integrado en Cluster → Registries (o conecta el tuyo), vuelve a publicar builds y añade nodos worker para réplicas stateless. Los volúmenes locales permanecen en su nodo.

Cluster → Registries y Nodes
docker node ls
docker service ls

Despliega una app o un worker con un comando

Ejecuta una app web, una API o un worker privado. caprover deploy empaqueta los archivos confirmados en local y compila directamente en tu VPS.

Dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY worker.py .
CMD ["python", "worker.py"]
$ caprover deploy
✓ Imagen compilada · Servicio Swarm actualizado

Apunta tu archivo captain-definition a ./Dockerfile antes de desplegar, sin OAuth obligatorio con un proveedor Git.

Publica un sitio estático

Sirve HTML plano o despliega el build de tu frontend directamente desde tu equipo.

Dockerfile
FROM nginx:alpine
COPY ./public/ /usr/share/nginx/html/
$ caprover deploy
✓ Imagen compilada · Servicio Swarm actualizado

Apunta tu archivo captain-definition a ./Dockerfile antes de desplegar, sin OAuth obligatorio con un proveedor Git.

Importa un stack Compose con imágenes existentes

Pega un YAML de Docker Compose compatible para crear aplicaciones gestionadas por CapRover. La versión 1.16 avisa sobre campos ignorados como build o redes personalizadas.

compose.yaml
services:
  web:
    image: nginx:alpine
  cache:
    image: redis:7-alpine
Apps → Docker Compose → Pega el YAML
✓ Stack validado · Servicios listos
